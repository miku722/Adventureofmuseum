## 📖 故事背景
深夜的博物馆，时钟指针疯狂倒转。你被困在了一个充满超自然气息的循环空间。每一张画作、每一件文物都可能隐藏着逃出生天的密码，也可能将你推入更深的轮回。唯有保持清醒，解开古老文明的谜题，才能找到那扇通往现实世界的“奇妙之门”。

### ✨ 游戏亮点
* 🌀 **轮回机制**：独特的循环解谜体验，每一次重来都会发现新的细节。
* 🎨 **视觉叙事**：基于 Figma 精心构筑的沉浸式艺术风格。
* 🧩 **逻辑挑战**：将历史文物与现代谜题结合，考验玩家的观察力。
